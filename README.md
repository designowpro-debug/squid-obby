# 魷魚遊戲 闖關挑戰 (Squid Obby)

Roblox 風格的 3D 魷魚遊戲跳躍闖關小遊戲。Three.js 已內嵌在單一 `index.html`，可離線開啟，也支援 iPad / 手機觸控。

▶️ 線上遊玩：https://designowpro-debug.github.io/squid-obby/

## 關卡
1. **跳格子踏石**（新手）：跳房子 1–8 號格子 → 檢查點 → 水上踏石 → 檢查點 → 兩塊慢速移動平台 → 終點。
2. **玻璃橋**：12 排玻璃，每排只有一片是強化玻璃；踩到的安全玻璃會保持顯示。中途有檢查點。
3. **椪糖跳台**：移動平台、旋轉圓盤、旋轉橫桿（會把你撞飛，要跳過去）、窄道雙橫桿、兩個檢查點。
4. **彈珠迴旋**：轉得更快的彈珠圓盤、圓盤上的旋轉橫桿、三支橫桿的窄道、快速移動平台，兩個檢查點。
5. **魷魚決戰（最終關）**：高速移動小平台、十字旋轉桿轉盤、更窄的三橫桿走道、轉盤上的橫桿，兩個檢查點，終點有獎金豬撲滿。

## 角色（開始後選擇）
| 角色 | 速度 | 跳躍 | 能力 |
|---|---|---|---|
| 菜鳥 | 慢 | 低 | 無（困難模式） |
| 培根頭 | 普通 | 高 | 空中二段跳 |
| 小咔啦 | 快 | 普通 | 按住 Shift／「衝」衝刺（消耗體力） |

掉下去會回到最後的檢查點 🚩。畫面顯示關卡、淘汰次數、總時間；通關後顯示總時間。

## 操作
- 電腦：WASD／方向鍵移動、空白鍵跳（培根頭再按一次＝二段跳）、Shift 衝刺（小咔啦）、滑鼠拖曳轉視角、滾輪縮放
- 平板／手機：左下虛擬搖桿移動、右下「跳」按鈕、「衝」按鈕（只有小咔啦）、拖曳畫面其他地方轉視角

測試用網址參數：`?level=1..5` 直接進入關卡、`&char=noob|bacon|kara` 指定角色。
原始碼在 `src/game.html`（Three.js 內嵌前的版本）。
